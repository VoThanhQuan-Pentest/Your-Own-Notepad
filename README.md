## English

### About

Command Vault is a native, offline desktop application designed for organizing, searching, and safely using technical command references—such as Linux, Nmap, Wireshark, tcpdump, Git, PowerShell, and Cisco configurations.

The local filesystem is the single source of truth: folders in the Explorer are real directories on your machine, and every command collection is a human-readable UTF-8 `.cmdnote` JSON file. Command Vault requires no database, cloud account, telemetry, internet connection, or background daemon.

---

### Highlights

- **Startup Mode Flow**: Choose between **Battery Saver** (energy-efficient, reduced CPU/GPU usage, zero decorative animations) and **Performance** (full animation, rapid indexing) at launch.
- **Progressive Workspace Loading**: Lightning-fast app launch; workspace trees and active files load progressively before background search indexing begins.
- **Native Tauri 2 Engine**: Built with Vanilla TypeScript, HTML, CSS, and Rust—no heavy frontend frameworks.
- **Compact Tables**: Dense, numbered references specifically optimized for port listings, scan modes, and technical flags.
- **AI Table Import**: Directly paste Markdown, TSV, or CSV tables generated by AI with automatic schema detection and duplicate filtering.
- **Instant Typo-Tolerant Search**: Global `Ctrl+K` search with accent normalization (e.g., `mat khau` matches `mật khẩu`) and fuzzy typo tolerance.
- **Safe & Local-First**: Explorer deletion routes to the System Trash. Writes are atomic with external-edit collision prevention.
- **Bilingual Interface**: Seamlessly supports both English and Vietnamese data structures.
- **Smooth Scaling**: Semantic UI scaling from 75% to 200% (`Ctrl++`, `Ctrl+-`, `Ctrl+0`) without blurry browser zoom.

### Installation Guide

#### 1. Kali Linux / Debian / Ubuntu

##### Option A: Install via `.deb` package (Recommended)
Download the latest `.deb` package from [Releases](https://github.com/VoThanhQuan-Pentest/Your-Own-Notepad/releases) or build it locally:
```bash
sudo apt install --reinstall ./CommandVault_0.11.0_amd64.deb
```
Launch the application from your terminal or Application Launcher:
```bash
command-vault
```

##### Option B: Run standalone AppImage
Download the `.AppImage` file, make it executable, and run:
```bash
chmod +x CommandVault_0.11.0_amd64.AppImage
./CommandVault_0.11.0_amd64.AppImage
```
> **Note:** If AppImage does not launch on Ubuntu 22.04+ or Debian, install `libfuse2`:
> ```bash
> sudo apt install libfuse2
> ```

##### Option C: Build from source
Prerequisites:
```bash
sudo apt update
sudo apt install pkg-config libwebkit2gtk-4.1-dev librsvg2-dev build-essential curl
```
Install Rust and Node.js:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# Install Node.js (v18+ recommended)
```
Clone and run in development mode:
```bash
git clone https://github.com/VoThanhQuan-Pentest/Your-Own-Notepad.git
cd Your-Own-Notepad
npm install
npm run tauri dev
```

##### Using the AppImage

Download the Windows installer (`.exe` or `.msi`) from [Releases](https://github.com/VoThanhQuan-Pentest/Your-Own-Notepad/releases) and run setup.

The compiled `.exe` / `.msi` will be located in `src-tauri\target\release\bundle\`.

### User Guide

1. **Launch & Choose Performance Mode**:
   * **Battery Saver**: Recommended for laptops on battery power. Turns off non-essential animations, throttles background indexing, and minimizes CPU/GPU load.
   * **Performance**: Provides instant rendering, rapid indexing, and fluid animations while plugged in.
   * *Tip:* Change your default preference anytime in **Settings → Startup mode**.
2. **Open / Create a Workspace**:
   * Select an empty directory or your existing folder containing `.cmdnote` files.
   * Real directories and `.cmdnote` files will be organized in the left Explorer tree.
3. **Working with Commands**:
   * Click **+ ADD SECTION** for standard command cards.
   * Click **+ ADD TABLE** to create a dense **Compact Table** (ideal for port scans, flags, and quick reference sheets).
   * Click the **COPY** button on any command row to copy it to clipboard.
4. **Fuzzy Search**:
   * Press `Ctrl+K` from anywhere in the app.
   * Search handles typos (e.g. typing `namp` still finds `nmap`) and ignores Vietnamese accents.
5. **Favorites**:
   * Click the heart icon on any folder, file, or command to pin it to the top of the Explorer.
6. **Zoom & Accessibility**:
   * Press `Ctrl++` to enlarge the interface (up to 200%).
   * Press `Ctrl+-` to decrease, or `Ctrl+0` to reset to 100%.

### AI Prompt Template for Generating Tables

When generating reference tables using LLMs (ChatGPT, Claude, Gemini, DeepSeek), copy and paste this standard prompt:

```text
Tôi sẽ gửi ảnh chụp hoặc dữ liệu văn bản bên dưới.

Hãy đọc nội dung và chuyển thành MỘT bảng Markdown tương thích với chức năng Paste Table của ứng dụng Command Vault.

- Chỉ trả về bảng Markdown.
- Không giải thích, không tiêu đề và không dùng code fence ``` .
- Dùng đúng các cột theo thứ tự:
  Command | Description | Example | Notes
- Mỗi command, port, chức năng hoặc mục dữ liệu là một hàng.
- Description viết ngắn gọn bằng tiếng Việt, giải thích mục đó dùng để làm gì.
- Example phải là ví dụ sử dụng cụ thể nếu dữ liệu có cung cấp.
- Notes chỉ dùng cho lưu ý quan trọng, cảnh báo hoặc thông tin bổ sung.
- Để ô trống nếu dữ liệu không cung cấp thông tin rõ ràng.
- Không tự bịa command, ví dụ hoặc thông tin không có trong dữ liệu.
- Không đặt command hoặc example trong dấu backtick `.
- Không xuống dòng bên trong một ô; nếu cần, nối nội dung bằng dấu “; ”.
- Nếu command chứa ký tự |, phải đổi thành \| để không làm hỏng bảng Markdown.
- Nếu nội dung không đọc rõ, ghi vào Notes với tiền tố “Không rõ:”.

Quy tắc riêng cho danh sách port:
- Ghi port và service chung trong cột Command.
- Port đứng trước, service đứng sau.
- Giữa port và service phải là MỘT ký tự Tab thật, không dùng nhiều dấu cách.
- Ví dụ:
  22/tcp	SSH
  443/tcp	HTTPS

- Description chỉ giải thích công dụng của port/service.

Quy tắc riêng cho command:
- Command chứa cú pháp hoặc câu lệnh chính.
- Description chứa công dụng.
- Example chứa ví dụ hoàn chỉnh.
- Notes chứa điều kiện sử dụng hoặc cảnh báo nếu có.

Dữ liệu hoặc ảnh cần chuyển:
[DÁN DỮ LIỆU HOẶC GỬI ẢNH TẠI ĐÂY]

## Tiếng Việt

### Giới thiệu

**Command Vault** là ứng dụng desktop offline dành cho các kỹ sư bảo mật (pentester), quản trị mạng và lập trình viên nhằm tổ chức, tra cứu và sử dụng an toàn các câu lệnh kỹ thuật (Linux, Nmap, Wireshark, tcpdump, Git, PowerShell, Cisco...).

Ứng dụng hoạt động theo triết lý **Local-First**: thư mục trên máy tính là nguồn dữ liệu duy nhất. Mỗi tệp lệnh là một file JSON `.cmdnote` chuẩn UTF-8 có thể đọc được bằng bất kỳ text editor nào. Command Vault **không dùng database, không cloud, không tài khoản, không theo dõi (telemetry) và không chạy tiến trình ngầm**.

---

### Tính năng nổi bật

* **Luồng khởi động tối ưu (Startup Mode Flow)**: Cho phép chọn **Battery Saver** (tiết kiệm pin tối đa, tắt hiệu ứng đồ họa, giảm tải CPU/GPU cho máy yếu) hoặc **Performance** (mượt mà, đầy đủ hiệu ứng và index tìm kiếm nhanh nhất).
* **Tải Workspace phân tầng (Progressive Loading)**: Ứng dụng hiển thị ngay lập tức; nạp trước cây thư mục và file đang mở, sau đó mới tiếp tục index nền trong Worker giúp tránh lag/đơ máy kể cả với thư mục chứa hàng nghìn lệnh.
* **Bảng Compact Table chuyên dụng**: Trình bày danh sách port, cờ lệnh hoặc tham số dưới dạng bảng gọn gàng, tự động đánh số thứ tự hàng.
* **Tích hợp dán bảng từ AI (Paste Table)**: Hỗ trợ copy/paste bảng Markdown, TSV (Excel/Google Sheets) hoặc CSV từ ChatGPT/Claude vào thẳng ứng dụng kèm bộ lọc chống trùng lệnh tự động.
* **Tìm kiếm thông minh toàn năng (`Ctrl+K`)**: Tìm kiếm theo thời gian thực, chấp nhận lỗi gõ phím (ví dụ `namp` vẫn ra `nmap`), không phân biệt dấu tiếng Việt (`mat khau` tìm được `mật khẩu`).
* **An toàn dữ liệu tuyệt đối**: Xóa tệp được đưa vào Thùng rác (System Trash) của hệ điều hành, không xóa vĩnh viễn. Ghi file atomic chống xung đột khi tệp bị chỉnh sửa ngoài.
* **Hỗ trợ phóng to giao diện (Semantic UI Scaling)**: Cho phép scale từ 75% đến 200% bằng phím tắt `Ctrl++`, `Ctrl+-`, `Ctrl+0` mà không làm mờ giao diện.

5. **Ghim Yêu thích (Favorites)**:
   * Bấm biểu tượng trái tim để đưa thư mục, tệp lệnh hoặc câu lệnh thường dùng lên nhóm **FAVORITES** ở đầu cây thư mục.
6. **Thu phóng giao diện & Tùy chỉnh theme**:
   * Dùng `Ctrl++` để tăng kích thước chữ/giao diện (hỗ trợ tới 200%).
   * Dùng `Ctrl+-` để giảm, và `Ctrl+0` để trở về 100%.
   * Vào **Settings → Appearance** để tùy biến màu sắc Dark/Light độc lập.
